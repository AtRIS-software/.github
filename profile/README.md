# AtRIS: Atmospheric Radiation Interaction Simulator

AtRIS is a research code for studying how energetic particles interact with planetary atmospheres and surfaces. It follows incoming radiation and the secondary particles it produces, calculating energy deposition and particle fluxes at different altitudes and depths. Applications include atmospheric chemistry, planetary shielding, radiation exposure, and the habitability of planets and exoplanets.

AtRIS was originally described by [Banjac, Herbst, and Heber (2018)](https://doi.org/10.1029/2018JA026042) and has since been used in studies of Earth, Mars, Venus, and exoplanets. The transport calculations in AtRIS make use of [Geant4](https://geant4.web.cern.ch/). 

The [AtRIS repository](https://github.com/AtRIS-software/atris) contains the simulator, Python tools for preparing and analysing simulations, and worked examples.
